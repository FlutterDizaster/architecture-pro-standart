# Задание 1. Карта IT-ландшафта и схема интеграции

Исходники в draw.io, рядом PNG для быстрого просмотра:

- `IT_landscape_map.drawio`: карта текущего ландшафта. В строках управления банка, в колонках бизнес-возможности второго уровня из Business Capability Map, в ячейках системы, через которые подразделение реализует возможность.
- `Integration_scheme.drawio`: схема интеграции с участниками процессов. На стрелках бизнес-сущности и тип обмена.

Цвет блоков на обеих схемах: синий для систем, которые разрабатывает банк, зелёный для платформ и коробок подрядчиков, оранжевый пунктир для внешних систем, жёлтый пунктир для ручной работы через почту и Excel.

## Что видно по карте

Почти вся операционка замыкается на АБС: в ней работают и отделения, и оба бэк-офиса. Ставки по депозитам живут только в Excel и ходят по почте, поэтому ни сайт, ни интернет-банк, ни кол-центр их не видят. Интернет-банк умеет только платежи и текущие счета, депозитов и кредитов в онлайне нет. У команды цифровой трансформации своих систем пока нет, строку оставил, чтобы потом сравнить с целевой картой.

Сайт и интернет-банк поставил в строку IT, потому что ими владеет и их развивает управление IT, бизнес-подразделения в них не работают. Сайт сейчас только показывает маркетинговую информацию, ближе всего это к digital-коммуникации с клиентами. Интернет-банк умеет платежи и открытие текущих счетов, то есть по сути заключение договоров на счёт, поэтому он в колонке «Управление договорами».

## Кредитный процесс

Участники: клиент, менеджер отделения, менеджер кредитования.

1. Клиент приходит в отделение, менеджер оформляет заявку на кредит в АБС.
2. Раз в сутки заявки уходят из АБС в Кредитный конвейер через интеграцию по БД.
3. Менеджер кредитования разбирает заявку в Кредитном конвейере. Конвейер вызывает систему скоринга по REST. Скоринг берёт данные БКИ онлайн, а данные о клиенте и платежах по кредитам получает раз в сутки из БД АБС. Номера платежей по кредитным договорам приезжают так же, раз в сутки из БД конвейера.
4. Менеджер принимает решение по оценке скоринга и параметрам заявки. Одобренная заявка получает финальный статус.
5. Раз в сутки одобренные кредиты уходят в АБС, и там деньги зачисляются на счёт клиента.

Из-за двух суточных обменов между заявкой и деньгами проходит несколько дней, а данные для скоринга отстают на сутки.

## Проблемы, которые мешают сделать депозиты онлайн

1. Интернет-банк пишет прямо в БД АБС (красная стрелка). БД АБС уже перегружена и масштабируется только вертикально, нагружать её онлайн-заявками нельзя.
2. Ставки считают вручную в Excel и рассылают по почте, единого источника ставок нет.
3. Депозитный и кредитный бэк-офисы по требованиям безопасности не видят данные друг друга, поэтому специальные ставки согласуют письмами, до часа на клиента.
4. Заявки из кол-центра обрабатывают в АБС вручную, а для клиента без звонка ставку узнают письмом прямо во время визита.
5. Обмены с Кредитным конвейером и скорингом идут раз в сутки через БД (фиолетовые стрелки), поэтому решение по кредиту за день не получить.

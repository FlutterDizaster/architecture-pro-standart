# architecture-pro-standart

Проектная работа спринта 3: цифровая трансформация банка «Стандарт».

- Task1: карта текущего IT-ландшафта и схема интеграции с описанием кредитного процесса (draw.io и PNG).
- Task2: требования по депозитам и кредитам в формате FURPS+.
- Task3: ADR открытия депозитов онлайн для MVP, диаграммы контекста и контейнеров C4.
- Task4: ADR передачи ставок в кол-центры, список задач по системам и RoadMap на год.
- Task5: ADR заявки на кредит онлайн, диаграммы контекста и компонентов C4.

Диаграммы C4 нарисованы в PlantUML, исходники `.puml` лежат рядом с PNG.
